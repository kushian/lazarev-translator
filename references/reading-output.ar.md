# دليل إخراج HTML وPDF

هذا المرجع يشرح تنفيذ تنسيق القراءة والطباعة المعتمد. راجع أيضاً [دليل المهارة العربي](../README.ar.md).

## الملفات النهائية

أخرج `النهائي/<العنوان العربي>.html` و`النهائي/<العنوان العربي>.pdf` افتراضياً. احتفظ بالتاريخ المعروف في الاسم إن كان المشروع يستخدمه. احفظ الملاحظات بصورة مستقلة باسم `<العنوان العربي> – مواضع الشك.html`.

تبقى ملفات Markdown بعلامات المقاطع داخل مجلد العمل للمراجعة. يجمع `scripts/assemble_book.py` النص؛ لا ينشئ HTML أو PDF بنفسه، ويلزم تنفيذ مرحلة التصدير التالية بعد التجميع.

## أمر الإخراج (استعمله ولا تبنِ HTML وPDF يدوياً)

```
python -X utf8 S/export_reading.py "<الملف المجمّع>.md" --out-dir <مجلد النهائي> \
   [--doubts "<الملف المجمّع> – مواضع الشك.md"] [--meta meta.json --index ترجمات/مقالات/index.json]
```

ينفّذ السكربت كل الخطوات التالية بمتصفح Chrome أو Edge المثبّت، دون أي مكتبة Python إضافية:
- يحوّل النص إلى HTML عربي دلالي من اليمين إلى اليسار.
- يضمّن ملف التنسيق والخطوط داخل الملف.
- يقسّم النص إلى صفحات A4.
- يطبع PDF من HTML نفسه.
- يفحص أن عدد صفحات PDF يساوي عدد الصفحات في HTML، وأن مقاسها A4، وأن النص العربي قابل للتحديد، وأن التقسيم لم يغيّر النص.

ويُخرج أيضاً ملف مواضع الشك بصيغة HTML منفصلاً، ويحدّث فهرس المقالات إلى المسارات النهائية.

إن خرج السكربت بالرمز 1 فاقرأ أسطر PROBLEM وأصلحها، ثم أعد التشغيل. وبعد نجاحه يبقى فحص الصفحات بالعين ضرورياً، فنجاح السكربت لا يغني عن المراجعة البصرية. الخطوات التالية توثّق ما يفعله السكربت، للإصلاح وللمحتوى غير المعتاد.

## خطوات التنفيذ

1. أكمل فحوص المطابقة والمصطلحات والمراجعة المعنوية، وسجّل مواضع الشك.
2. اجمع النص المراجع في `work/assembled/`. عند استخدام أمر `single` مرّر هذا المسار عبر `--out-dir`. تجميع الكتب يستخدمه افتراضياً.
3. حوّل Markdown بمحلّل يدعم بنيته إلى HTML دلالي، مع الحفاظ على الفقرات والعناوين والتوكيد والروابط والجداول والحواشي. لا تستخدم حذف الرموز بالتعبيرات النمطية بديلاً عن المحلّل.
4. أنشئ مستند UTF-8 يحتوي `lang="ar"` و`dir="rtl"`، وبيان viewport، وعنواناً واضحاً، والنص داخل عنصر `main`. اعرض البيانات الوصفية في رأس مقروء بدلاً من إظهار YAML.
5. ضمّن محتوى `assets/reading.css` داخل `style`. حوّل رابطَي الخطوط إلى بيانات مضمّنة «data URLs» من `assets/fonts/ReadexPro-Light.ttf` و`assets/fonts/ReadexPro-Bold.ttf` ليكون الملف مستقلاً.
6. افتح HTML بمحرك عرض يدعم العربية، وانتظر تحميل الخطوط عبر `document.fonts.ready`. نفّذ التقسيم على نافذة واسعة أو تحت وسيط الطباعة حتى لا يعمل تخطيط الهاتف أثناء القياس.
7. حمّل `assets/paginate-reading.js` ثم استدعِ `await window.paginateReading()`. يُنشئ صفحات `.a4-page` ويقسّم الفقرات الطويلة مع الحفاظ على الوسوم الداخلية، ويفحص بقاء النص بعد توحيد المسافات البيضاء.
8. احفظ DOM الناتج في ملف HTML النهائي، كي لا يحتاج القارئ إلى إعادة تنفيذ التقسيم عند فتحه.
9. أضف للصفحات الصريحة `@page { size: A4; margin: 0; }`. اطبعها إلى PDF بهوامش خارجية صفرية ومن دون رأس المتصفح وتذييله، لأن الصفحة تتضمن الهوامش الداخلية والترقيم بالفعل.
10. سلّم روابط HTML وPDF بعد إكمال المراجعة التالية.

## القيم المعتمدة

النص بخط **Readex Pro Light**، وزن 300، وحجم 14 نقطة. العناوين بخط **Readex Pro Bold**، وزن 700، وأحجام 23 و18 و16 نقطة بحسب المستوى. تباعد الأسطر 2.1، والمسافة بعد الفقرة 1.25em.

الفقرة مضبوطة على الجانبين، وسطرها الأخير إلى اليمين. تبقى العناوين والأسئلة القصيرة والحوار والإشارات غير الكلامية بمحاذاة اليمين. لا تُضف مسافات يدوية أو تطويلاً للحروف لمحاكاة الضبط.

صفحة A4 أبعادها 210 × 297 مم، بهوامش 22 مم من الأعلى والجانبين و24 مم أسفلها. ارتفاع مساحة المحتوى 251 مم. لا تضف هوامش أو أرقام صفحات ثانية من محرك الطباعة.

## العرض المتجاوب

على الشاشات الواسعة تظهر الصفحات منفصلة مع أرقامها. عند عرض 900 بكسل أو أقل، تعمل قواعد `@media screen` لإعادة تدفق النص في عمود يناسب النافذة، وإخفاء حدود الصفحات وأرقامها.

هذا التغيير خاص بالشاشة. يجب أن تحتفظ الطباعة بصفحات A4 حتى إذا بدأت من هاتف أو نافذة ضيقة. لا تطبّق قياسات الشاشة الصغيرة على ملف PDF.

## المراجعة قبل التسليم

- طابق عدد صفحات HTML مع عدد صفحات PDF، وافحص أبعاد صفحات PDF.
- افحص الحفاظ على النص وترتيبه بعد التقسيم، ثم راجع مواضع القطع والعناوين مع الفقرات التالية.
- راجع صور صفحات من البداية والمنتصف والنهاية، إضافة إلى الجداول أو المواضع ذات التخطيط الصعب.
- افحص اتصال الحروف العربية، واتجاه النص، والتشكيل، والهوامش، والترقيم، وعدم التداخل أو القص.
- تأكّد من قابلية تحديد نص PDF والبحث فيه.
- افحص HTML بعروض 390 و768 و1280 بكسل، مع عدم وجود تمرير أفقي غير مقصود.
- اختبر وسيط الطباعة في عرض ضيق للتأكد من بقاء صفحات A4.

لا تعتمد الملف إذا فشل فحص بقاء النص أو تجاوز أحد العناصر مساحة الصفحة. لا يكفي نجاح أمر التصدير لإثبات سلامة التنسيق.

## الجداول والأدوات الناقصة

مساعد التقسيم الحالي مخصّص أساساً للفقرات. لا تمرّر إليه جدولاً أطول من الصفحة دون معالجة مناسبة. اترك ملاحظات الشك ذات الجداول في HTML متصل بعرض مناسب، أو استخدم محركاً يدعم تقسيم الجداول وتكرار رؤوسها. لا تحذف الصفوف أو تقصّها لتلائم الصفحة.

استخدم الأدوات المتاحة محلياً أو في بيئة العمل أولاً. اطلب الإذن قبل تثبيت اعتماد جديد. إذا تعذّر إخراج PDF، احتفظ بـHTML واذكر العائق المحدّد؛ لا تنشئ ملفاً شكلياً ولا تعلن اكتمال PDF.

بالنسبة إلى المقالات، حافظ على فهرس منع التكرار، واجعل `file_ar` يشير إلى HTML النهائي، وأضف `file_pdf` بعد نجاح إخراجه.
